## Our projects

| Project | What it does | Repository |
| --- | --- | --- |
| **ReMCP** | Remote MCP access to explicitly paired computers, including files, terminals, desktop UI, browser automation, and diagnostics. | [ReMCP releases and integrations](https://github.com/getremcp/remcp) |
| **Docsy MCP Plugin** | Source-linked, version-aware documentation for AI clients including ChatGPT, Claude Code, Codex, and Cursor. | [Docsy plugin](https://github.com/getremcp/docsy-plugin) |
| **Docsy SDK & CLI** | TypeScript SDK, CLI and Gemini CLI extension for working with developer documentation. | [Docsy SDK and CLI](https://github.com/getremcp/docsy) |

## Get started

- **Automate a paired computer:** start with the [ReMCP README](https://github.com/getremcp/remcp#readme) and its supported-client setup guides.
- **Connect development documentation to an AI assistant:** use the [Docsy MCP Plugin](https://github.com/getremcp/docsy-plugin#readme).
- **Use documentation in code or a terminal:** explore the [Docsy SDK & CLI](https://github.com/getremcp/docsy#readme).

## Security and release policy

Pair only computers you own or are authorized to operate. Review permissions and requested actions before granting access. Report suspected ReMCP security issues using its [security policy](https://github.com/getremcp/remcp/security/policy).

The project repositories above contain **public distribution artifacts and documentation**. Core development, private infrastructure and deployment configuration are maintained separately. Official ReMCP releases are published only from [getremcp/remcp](https://github.com/getremcp/remcp/releases); Docsy maintains separate plugin and SDK/CLI release channels.

## Help and feedback

For ReMCP bugs and requests, use [ReMCP Issues](https://github.com/getremcp/remcp/issues). For Docsy integration issues, use [Docsy Plugin Issues](https://github.com/getremcp/docsy-plugin/issues). Check each project's README before opening an issue.
